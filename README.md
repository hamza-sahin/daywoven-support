# Daywoven support

Daywoven is an iPhone app for two linked partners: daily questions, private answers, mutual reveal and a shared space.

- [Help](https://daywoven.optalgo.com/support)
- [Privacy](https://daywoven.optalgo.com/privacy)
- [Terms](https://daywoven.optalgo.com/terms)

During the private beta, use **Send Beta Feedback** in TestFlight to reach the developer. You can also open an issue here for a non-sensitive question or bug report.

**Never post recovery codes, credentials, private answers or personal photos in a public issue.** Include only the app version, iOS version and steps that reproduce the issue.

This repository contains support information only. The application source and user data are private.
